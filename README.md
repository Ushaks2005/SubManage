

\# SubManage – Customer Subscription \& Service Usage Management Platform



\## Project Overview

SubManage is a web-based platform designed to manage customers, subscription plans, subscriptions, payments, and service usage.



\## Technology Stack

\- \*\*Backend:\*\* Java 21, Spring Boot

\- \*\*Database:\*\* MySQL

\- \*\*Database Access:\*\* JdbcTemplate

\- \*\*Frontend:\*\* Existing SubManage frontend



\## Project Structure

```text

SubManage-GitHub/

├── backend/

├── frontend/

├── dataset/

│   └── subscription\_management\_schema.sql

├── .gitignore

└── README.md

```



\## Database Setup

1\. Open MySQL Workbench.

2\. Create a database named `subscription\_management`.

3\. Import `dataset/subscription\_management\_schema.sql`.

4\. Configure your local database connection.



\## Backend Setup

1\. Open the `backend` folder in IntelliJ IDEA.

2\. Configure your local database credentials.

3\. Run the Spring Boot application.
